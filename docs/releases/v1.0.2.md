## 1. 概述

SoundPipe 把电脑里播放的声音（整系统或指定应用）实时转发到虚拟声卡的录音端，让 QQ、微信、录音机、会议/直播软件把它当作**麦克风**使用。通话时可以同时混入真实人声，音乐与人声增益独立可调。

```
QQ音乐 / 网页 / 任意应用 ──→ SoundPipe 捕获 ──→ 虚拟声卡输入端
                              （人声可叠加 ↑）        │ 内核桥
                                    虚拟声卡录音端 ←──┘
                                          ↓
                          QQ / 微信 / OBS / 录音机（选它当麦克风）
```

## 4. 快速开始

1. 安装虚拟声卡（VB-CABLE 或 Voicemeeter）并按提示重启。
2. 安装 SoundPipe（需要管理员权限，可选开机自启）。
3. 首次启动后点击「开始转发」：
   - 自动选中虚拟声卡输入端作为转发目标；
   - 自动把系统默认麦克风指向对应录音端；
   - 若默认输出被吸入虚拟设备，自动切回物理扬声器。
4. 打开 QQ / 微信 / 录音软件，麦克风保持「默认」即可。
5. 点窗口右上角 X 只是收进托盘，转发继续；托盘右键「退出」才真正结束。

## 5. 功能清单

- **两种转发模式**
  - 整系统：转发电脑当前播放的所有声音；
  - 指定应用：只转发选中的进程（含子进程树），基于 WASAPI 进程循环捕获，无需注入，运行中可增删应用。
- **麦克风混音**：真实麦克风与音乐叠加，人声/音乐增益独立调节。
- **每应用独立音量**：每个勾选的应用有独立滑条（0–200%，旁显百分比），按进程名持久化。
- **双输出**：转发目标 + 可选监听设备，边转发边自己听。
- **一键自动配置**：自动选目标、设置默认麦克风、保护默认输出，幂等。
- **链路诊断**：向目标播放测试音并从录音端采样，定位断点；Voicemeeter 桥断时自动拉起本机已装实例。
- **稳定性**
  - 捕获/输出异常自动重启（1s × 3 次，超限弃源并通知，稳定 10s 后计数重置）；
  - 设备热插拔/默认设备变化自动重建输出；
  - 时钟漂移丢样/补样 + crossfade，无爆音；
  - 混音按需产出，避免「半个包 + 静音空洞」造成的发闷/沙哑；
  - tanh 软限幅，多源叠加不削波。
- **桌面端**：深色工作台、三路电平、发声应用列表、托盘常驻、开机自启、设置持久化、高对比度与减弱动效适配。

## 6. 本版变更（相对内部 1.0.1 构建）

### 修复

- 「指定应用」模式下音乐增益不生效的问题。
- 混音饥饿判定改为按「最后一次写入时间」等待，修复 5ms 级小包源被周期性强制补零造成的发闷/空洞，并对补零告警做节流。
- 取消勾选的应用会被「按名恢复」立即重新勾回的问题。
- 输出链路仅支持 float32 设备格式的问题，现支持 PCM16 / PCM24 / PCM32，并修复高采样率 + 大缓冲下的截断。
- 链路诊断的测试音改为按设备实际格式编码，避免 PCM 设备上误判。
- 监听输出失败会拖累主转发的问题：失败后自动摘除监听环，且不再在 WASAPI 回调线程上同步停止。
- 首次启动只打开界面就被修改系统默认设备的问题，改为首次点击「开始转发」时执行自动配置。
- 程序捕获等待增加轮询兜底，避免个别驱动不置位事件时「启动成功但没有声音」。
- 清理已退出的勾选 PID，避免 PID 复用后误转发。
- 麦克风「系统默认」现在确实优先使用系统默认设备（仅在其为虚拟端时回退到物理麦克风）。

### 改进

- 新增每应用独立音量（F6）并按进程名持久化到 `settings.json`。
- 麦克风增益、音乐增益、应用增益三者关系明确：应用音量与总音乐增益相乘，互不覆盖。
- 安装包产物、本地工具目录不再进入版本库；补充 `dotnet.ps1` 构建入口与 MIT 许可证。
